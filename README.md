# Velira Web

Official source for **Velira Web** — websites, Telegram bots and business automations that turn clicks into qualified enquiries.

## Public site

<https://madbod77.github.io/velira-web/>

## Build

```bash
bash scripts/build-sites-static.sh
```

The production bundle is generated in `dist/` from an explicit allowlist of public pages and assets. Lead delivery secrets are supplied only through the hosting environment and are never committed to the repository.
